# Assignment 4 - Custom VPC with EC2

## Project Goal

Create a custom AWS network and deploy an EC2 instance inside it using Terraform.

## Architecture

VPC
├── Public Subnet
├── Internet Gateway
├── Route Table
├── Security Group
└── EC2 Instance

## Resources Created

* Custom VPC
* Public Subnet
* Internet Gateway
* Route Table
* Route Table Association
* Security Group
* EC2 Instance

## Terraform Concepts Used

* AWS Networking
* Resource Dependencies
* VPC Configuration
* Security Groups
* Route Management

## Outcome

Successfully built a custom AWS network and deployed an EC2 instance with internet connectivity.
