# Terraform AWS Practice

This repository contains hands-on Terraform projects created to learn Infrastructure as Code (IaC) on AWS. The projects progress from basic EC2 provisioning to custom networking and automated server configuration using User Data scripts.

## Technologies Used

* Terraform
* AWS EC2
* AWS VPC
* Elastic IP
* Internet Gateway
* Route Tables
* Security Groups
* User Data
* Git & GitHub

## Projects

### Assignment 1 - EC2 Default Deployment

Launch a basic EC2 instance using Terraform in the default VPC.

### Assignment 2 - EC2 with Elastic IP

Create an EC2 instance and associate a static Elastic IP.

### Assignment 3 - Multi-Region EC2 Deployment

Deploy EC2 instances in multiple AWS regions using provider aliases.

### Assignment 4 - Custom VPC with EC2

Build a custom AWS network including VPC, subnet, route table, internet gateway, security group, and EC2 instance.

### Assignment 5 - Apache Web Server using User Data

Launch an EC2 instance that automatically installs and configures Apache using Terraform User Data.

## Learning Outcomes

* Infrastructure as Code (IaC)
* Terraform resource management
* AWS networking fundamentals
* Multi-region deployments
* Security group configuration
* EC2 provisioning automation
* User Data scripting
* Terraform state management
